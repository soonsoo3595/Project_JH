## 실수와 어려웠던 점

문제·영향·원인, 시도한 방법과 결과, 해결 과정과 재발 방지를 남긴다. 없는 실수나 어려움을 만들어 적지 않는다.

## 필요한 검증과 인수인계

결론에 필요한 검증은 실행 결과와 미실행을 구분한다. 남은 문제·다음 작업에 필요한 정보·사용자 결정 대기 사항이 있을 때만 적는다. 전체 상태 변경은 PM에 요청하며 별도 작업 트리에 자동 공유된다고 가정하지 않는다.
